# MadLib.py

A simple interactive Mad Libs game that asks users to enter an adjective, noun and verb. Their answers are combined to create a personalised and potentially hilarious sentence!

**Concepts learned:**
- Collecting user input with `input()`
- Storing information in variables
- Working with strings
- Displaying output using `print()`

# MadLib_Challenge.py

An extended version of the Mad Libs game! Users enter an adjective, noun, verb and animal to generate a personalised, silly sentence.

**Concepts learned:**
- Collecting multiple inputs using `input()`
- Storing user responses in variables
- Combining strings and variables
- Displaying formatted output using `print()`

## How to Run
1. Download `MadLib_Challenge.py`.
2. Run the file using Python.
3. Enter an adjective, noun, verb ending in `-ed` and an animal.
4. Enjoy your generated Mad Lib!

## Example Output

```text
Please enter an adjective: silly
Please enter a noun: cat
Please enter a verb ending in -ed: jumped
Please enter an animal: elephant

Your Madlib:

The silly cat jumped over the lazy brown elephant.
```
